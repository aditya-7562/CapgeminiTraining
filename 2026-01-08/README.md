# Day 13 – OOP Abstraction (2026-01-08)

## Topics Covered
- **Abstraction:** Definition, purpose, and implementation.
- **Abstract Classes vs. Concrete Classes.**
- **Abstract Methods vs. Concrete Methods.**
- **Runtime Polymorphism** with abstract references.

## Programs Implemented
- `oops6.java`: Core demonstration of Abstract classes, mixed static/non-static members, and constructors in abstract classes.
- `oops6P1.java`: Practice exercise implementing abstract methods in a subclass.
- `Area.java`: Polymorphism example calculating areas of different shapes (Rectangle, Triangle, Circle).
- `oops6.md`: Detailed notes on Abstraction concepts.

## Key Takeaways
- An abstract class cannot be instantiated but can have constructors.
- If a class has an abstract method, the class must be abstract.
- Concrete subclasses must override all inherited abstract methods.
