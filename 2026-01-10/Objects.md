# Object Class in Java

## 1. Overview
*   **Superclass:** The `Object` class is the root of the class hierarchy. Every class in Java has `Object` as a superclass (directly or indirectly).
*   **Package:** `java.lang`
*   **Purpose:** It provides methods that are common to all objects.

## 2. Common Methods

### toString()
*   **Return Type:** `String`
*   **Default Behavior:** Returns a string consisting of the class name, the `@` symbol, and the unsigned hexadecimal representation of the object's hash code (e.g., `Objects@372f7a8d`).
*   **Purpose:** Used to return the string representation of an object.
*   **Why Override?** The default output is not very informative. Overriding it allows us to print the actual data (state) of the object instead of its memory address.

### hashCode()
*   **Return Type:** `int`
*   **Purpose:** Returns an integer value generated by a hashing algorithm.
*   **Usage:** It is primarily used in hashing-based collections like `HashMap`, `HashSet`, etc., to determine the bucket location where the object will be stored.

### equals(Object obj)
*   **Return Type:** `boolean`
*   **Default Behavior:** Compares the memory addresses of the objects. It returns `true` only if both references point to the exact same object instance (same as `==`).
*   **Why Override?** To perform **logical equality** checks (comparing the actual data/content of objects) rather than reference equality.

### getClass()
*   **Return Type:** `Class<?>`
*   **Purpose:** Returns the runtime class of the object. It can be used to get metadata about the class, such as its name (`getClass().getName()`).

---

## 3. Comparison: `==` vs `equals()`

| Feature | `==` Operator | `equals()` Method |
| :--- | :--- | :--- |
| **Type** | Operator | Method |
| ** Comparison** | Reference Comparison (Address comparison) | Content Comparison (if overridden) |
| **Default** | Checks if both references point to same location | Checks reference equality (same as `==`) |
| **Customizable** | No | Yes (can be overridden) |
