# Capgemini Training - Java Repository

## Purpose
This repository acts as a persistent record of Java training exercises and projects developed during the Capgemini training program. It demonstrates a progression from core fundamentals to advanced Object-Oriented Programming concepts, Enterprise Java technologies, and Testing frameworks.

## Structure
The repository is organized into:
*   **Core_Java:** Date-stamped directories (YYYY-MM-DD) containing daily exercises and notes.
*   **Capgemini_JDBC:** JDBC implementation examples.
*   **HibernateDemo:** Hibernate ORM project.
*   **JUNITT5:** JUnit 5 testing examples.
*   **mockitoDemo:** Mocking framework examples with Mockito.

## Learning Progression & Key Topics

### Core Java
*   **Fundamentals:** Data types, control flow, operators, loops.
*   **Logic Building:** Algorithms, number theory problems, iterative patterns, recursion.
*   **Object-Oriented Programming (OOP):**
    *   Classes, Objects, Constructors.
    *   Inheritance, Polymorphism (Overloading & Overriding).
    *   Encapsulation, Abstraction (Abstract Classes & Interfaces).
*   **Data Structures & Collections:**
    *   Arrays, Strings.
    *   List (ArrayList, LinkedList, Vector, Stack).
    *   Set (HashSet, TreeSet).
    *   Map (HashMap, TreeMap).
    *   Iterators, Comparable & Comparator.
*   **Java 8 Features:**
    *   Lambda Expressions.
    *   Functional Interfaces.
    *   Stream API.
    *   Method References.
*   **Advanced Concepts:**
    *   Multithreading (Thread Class, Runnable, Thread Pools).
    *   Regular Expressions (Regex).
    *   Exception Handling.
    *   Memory Management (Garbage Collection).

### Enterprise & Frameworks
*   **JDBC:** Database connectivity, CRUD operations.
*   **Hibernate:** Entity mapping, SessionFactory, Transaction management.
*   **Testing:**
    *   **JUnit 5:** Unit testing framework.
    *   **Mockito:** Mocking dependencies for isolation testing.

## Technology Stack
*   **Language:** Java
*   **Build Tools:** Maven (for Hibernate, JUnit, Mockito projects)
*   **Version Control:** Git
*   **IDE:** Eclipse / IntelliJ IDEA

## How to Run
*   **Core Java:** Compile and run individual files using `javac` and `java`.
    ```bash
    cd Core_Java/2026-02-07
    javac P1.java
    java P1
    ```
*   **Maven Projects:** Use `mvn clean install` or run via IDE.
