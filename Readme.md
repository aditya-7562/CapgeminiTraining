# Capgemini Training – Java Practice

This repository contains Java practice programs developed during Capgemini training sessions.  
It is organized **day-wise** to reflect consistent, structured hands-on learning.

## Repository Structure
- Each folder represents a **training date** (e.g., `2025-12-18`).
- Source code is organized by daily practice topics.
- Contains solutions to various algorithmic and logic-building problems.

## Daily Progress & Topics

### 📅 2025-12-18: Java Fundamentals
*   **Topics:** Data Types, Primitive Variables, Basic Arithmetic.
*   **Exercises:** 
    *   Sum & Average calculation.
    *   Variable swapping.
    *   Temperature conversion.
    *   SDLC (Software Development Life Cycle) overview.

### 📅 2025-12-19: Conditional Logic
*   **Topics:** `if-else`, Logical Operators.
*   **Exercises:**
    *   Checking positive/negative/zero signs.
    *   Vowel vs. Consonant checks.
    *   Finding Max/Min numbers.
    *   Divisibility rules (Divisible by 3, 5, 7).
    *   Student grading logic.

### 📅 2025-12-20: Switch Cases & Real-world Logic
*   **Topics:** `switch` statements, Complex Conditionals.
*   **Exercises:**
    *   **Area Calculator:** Circle, Rectangle, etc.
    *   **Employee Management:** Designation finder.
    *   **Ticket Booking System:** Logic for booking flows.
    *   Leap year validation.
    *   Arithmetic operations using switch.

### 📅 2025-12-23: Loops & Iteration
*   **Topics:** `for`, `while`, `do-while` loops.
*   **Exercises:**
    *   Factorial calculations.
    *   FizzBuzz problem.
    *   Finding factors of a number.
    *   Various loop-based pattern and logic problems.

### 📅 2025-12-24: Methods & Digit Logic
*   **Topics:** Modular Programming (Methods), Number Processing.
*   **Exercises:**
    *   **Digit Separation:** Extracting and processing individual digits of numbers (multiple variations).
    *   Method creation and invocation exercises.

### 📅 2025-12-26: Arrays & Recursion
*   **Topics:** Array manipulation, Recursive functions, Type Casting.
*   **Exercises:**
    *   Basic Array operations and traversals.
    *   Solving problems using Recursion.
    *   Understanding Type Casting (`TypeCasting.md`).
    *   Documentation on Arrays (`Arrays.md`).

### 📅 2025-12-27: Array Problem Solving
*   **Topics:** Advanced Array Logic.
*   **Exercises:**
    *   Continuation of complex array-based problems (filtering, searching, modifying).

### 📅 2025-12-29: Object-Oriented Programming (OOP)
*   **Topics:** Introduction to OOP concepts, Static vs Instance members, Variable Shadowing, `this` keyword, Method Overloading.
*   **Exercises:**
    *   **OOP Concepts:** Comprehensive documentation and examples (`oops.md`, `oops.java`).
    *   **Processor Class:** Logic demonstrating `this` keyword, instance methods, and variable shadowing (`Processor.java`).
    *   **Code Tracing:** Complex execution flow with static blocks and methods (`codeTracing.java`).
    *   **Main Method Overloading:** Demonstrating that `main` can be overloaded (`mainOverload.java`).
