# Capgemini Training - Java Repository

## Purpose
This repository acts as a persistent record of Java training exercises and projects developed during the Capgemini training program. It demonstrates a progression from core fundamentals to advanced Object-Oriented Programming concepts.

## Structure
The repository is organized into date-stamped directories (YYYY-MM-DD). Each folder corresponds to a specific training day and contains the source code and relevant notes for that session. Detailed documentation for specific topics resides within the respective daily folders.

## High-Level Topics
- **Java Fundamentals:** Data types, control flow, operators.
- **Logic Building:** Algorithms, number theory problems, iterative patterns.
- **Data Structures:** Arrays, String manipulation.
- **Object-Oriented Programming:** Classes, Objects, Inheritance, Polymorphism, Encapsulation.
- **Advanced Concepts:** Recursion, Memory management (Deep vs. Shallow copy).

## Technology
- **Language:** Java
- **Version Control:** Git

## Training Duration
Approximately 4 months.
