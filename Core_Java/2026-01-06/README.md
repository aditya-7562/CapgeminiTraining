# Day 11 – OOP Relationships & Inheritance (2026-01-06)

## Topics Covered
- Relationships: HAS-A (Aggregation & Composition) vs. IS-A (Inheritance).
- Inheritance Types: Single, Multilevel, Hierarchical, Multiple (Interfaces), Hybrid.
- Class Loading vs. Object Creation Execution Order.
- `super()` vs `this()` keywords.

## Programs Implemented
- `oops4.java`: Examples of Aggregation, Composition, and Inheritance.
- `oops4.md`: Detailed notes on relationships and execution flow.

## Key Takeaways
- Understanding the lifecycle of objects within relationships (Weak vs. Strong).
- Mastering the strict order of initialization (Static -> Instance -> Constructor).
- Distinguishing between parent and current class constructor calls.
